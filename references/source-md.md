# 阶段 1：整理原文 MD 并核对

后面每一步都以这份 MD 为底本。这里多出一个错，后面就要在译文、引文、润色里各查一遍，所以值得在翻译前核对清楚。

## 输入不同，做法不同

| 手上的材料 | 做法 |
| --- | --- |
| 带文字层的 PDF | 抽取文字，再清理换行、页眉页脚、连字符 |
| 用户给的 OCR 结果 | 以它为底稿，对照页面图片修正 |
| 只有扫描页，没有 OCR | 把页面当图片读，分批转写。先告诉用户这样更慢、更贵，问题页也更多 |
| EPUB / HTML | 按结构解析，不要按版面抽文字。保留强调、列表、链接、对齐和分隔符，并统计块数，确保每个块都进了 MD |
| TXT | 直接整理，章节边界靠人工判断 |

## 输出格式

先得到一份全书的 `source/book.md`，然后拆章。全书 MD 的约定：

- 每个序言、章节、附录用一个一级标题 `# 标题`，拆章就靠它。书名页不算一章：书名、副标题、作者写进 `project.json`，版权页信息记入 `collation.md`，都不放进 MD。
- 换页处单独一行写 `<!--p.37-->`，页码用原书印刷页码。这样后面核对、记录引文出处时能直接翻到原书那一页。
- 脚注或尾注全部移到本章末尾，放在 `## Notes` 标题下（原语言的"Anmerkungen"之类也统一改成这个），用 `1. ` 有序列表，每章从 1 重新编号，正文写 `[1]`。原书全书连续编号或按页编号的，记下新旧编号的对应关系。
- 去掉页眉页脚和孤立页码；修复行末连字符和断行；跨页的段落要接上。
- 原书的斜体、小标题、引文块、表格按 Markdown 保留。图片提到 `source/images/`，在原位引用，图内文字单独记下。

示例：

```markdown
# Chapter 3: The First Phase

<!--p.37-->
The land reform began in the north.[1] It spread unevenly...

## Notes

1. W. Hinton, *Fanshen*, New York, 1966, p.12.
```

## 拆章和加锚点

```bash
python <skill>/scripts/booktool.py split source/book.md --out source/chapters
```

每章成为 `NN_标题.md`，每个段落前加上 `<!--b012 p.37-->` 形式的锚点（注释区除外）。锚点是原文段落和译文段落一一对应的依据，所以**拆章之后就不要再重新编号**。如果发现漏了一段，给它一个新编号（比如接着最大号往后排）插在正确的位置，译文里也同样插入，这样已有的对应不会被打乱。

## 与原书核对

这一步是用户流程里明确要求的，不能跳过，但也不用假装做到逐字校对。

1. 跑机械检查，逐条处理：

   ```bash
   python <skill>/scripts/booktool.py source-check source/chapters
   ```

   它会抓反复出现的短行（多半是页眉）、残留的行末连字符、疑似断开的段落、孤立页码、替换字符、注释对不上、页码跳号。这些是疑点，确认是误报的不用改，也不用记录。

2. 对照原书目视核对，优先看这些地方：每章的首页和末页、页眉换章处、表格、注释区、数字和年代密集的段落、有外文或特殊字符的段落，再加上每章随机抽几页。OCR 容易错的字符要留心：`rn/m`、`l/1/I`、`0/O`、丢失的变音符号。

3. 把核对情况写进 `source/collation.md`，至少包括：底本来源和版本、核对了哪些页、发现并修改了什么、还有哪些存疑。

   ```markdown
   ## 第 3 章（原书 pp.37–62）
   - 目视核对：pp.37、38、45、51、61、62；注释全部
   - 修正：p.45 "rnodern" → "modern"；p.51 表 3 第二行数字串行
   - 存疑：p.51 脚注 4 页面污损，"1953" 或 "1958"，待用户看纸本
   ```

**没有原书可对时**（只有 TXT、EPUB、HTML）：把 MD 和底本文件对读或比对块数，写明"未与纸本或页图核对"。这种情况没有页码，锚点不带 `p.` 也可以。

用户如果想亲自核对，就把核对清单交给用户，不要代为声称已核对。

## 原文疑点怎么处理

原文本身的错误（印错的日期、前后矛盾）不要在这一步改掉。MD 要忠实于原书，疑点记下来，到翻译时再决定是否加译注。OCR 错误才在这里改。

## 完成标准

- `source-check` 的问题都已处理或记录原因；
- 章节文件的数量和顺序与原书目录一致，序言、附录、作者说明都没落下；
- `collation.md` 写明了实际核对范围。
