# 阶段 2：专有名词总表

逐章翻译之前先建好这张大表。全书几十万字，只有译名全都从同一张表取，才不会第 3 章一个译法、第 12 章另一个译法。

## 表的结构

`glossary/glossary.csv`，UTF-8 编码，列如下：

| 列 | 含义 |
| --- | --- |
| `type` | person 人名 / place 地名 / work 著作报刊 / org 机构组织 / event 事件 / term 术语概念 / other |
| `source` | 原文写法（原文语言）。别的写法放 `aliases_source`，用 `\|` 分隔 |
| `en` | 英文写法。**原文是英语时留空；原文是其他语言时要填，这样就是原文、英文、中文三语表** |
| `zh` | 采用的中文译名 |
| `aliases_zh` | 同样可接受的中文写法（比如简称），用 `\|` 分隔 |
| `forbidden_zh` | 明确不用的译法，用 `\|` 分隔。出现在译文里，`check` 会报错 |
| `status` | `verified` 已查证 / `provisional` 暂译 / `keep_original` 保留原文 / `conflict` 有冲突待定 |
| `basis` | 依据：中文维基、某中译本、学界通行、官方资料等 |
| `url` | 查证链接 |
| `note` | 说明：同名区分、争议、适用范围 |

示例（原文为德语）：

```csv
type,source,en,zh,aliases_source,aliases_zh,forbidden_zh,status,basis,url,note
work,Das Kapital,Capital,《资本论》,Kapital,,《资本》,verified,人民出版社中译本,,
person,Rosa Luxemburg,Rosa Luxemburg,罗莎·卢森堡,,卢森堡,,verified,中文维基百科,https://zh.wikipedia.org/wiki/罗莎·卢森堡,
```

## 建表步骤

1. **提候选。** 拉丁字母和西里尔字母文字可以先让脚本提高频专名，它只是起点，普通词也会混进来，罕见的专名则可能漏掉：

   ```bash
   python <skill>/scripts/booktool.py terms source/chapters --glossary glossary/glossary.csv --out glossary/candidates.tsv
   ```

   默认只列出现 2 次以上的，短书加 `--min-count 1`。德语名词都大写，普通词会大量混入，这一步基本靠通读。韩文、日文、阿拉伯文等脚本提不准，也要通读提取。无论哪种语言，都要再通读一遍，补上脚本看不出的内容：概念术语、反复出现的说法、组织简称、作者特有的造词。书后的索引和人名表如果有，是极好的来源。

2. **分批查证。** 按类型分批，用搜索工具查，把依据写进 `basis` 和 `url`。不同类型的来源优先级不同：

   | 类型 | 依次参考 |
   | --- | --- |
   | 人名 | 该人物已有的中文著作、中译本署名 → 中文维基百科（注意看简体转换后的写法）→ 学界论文和社区讨论里的常用译法 → 权威辞书、图书馆规范档 |
   | 地名 | 中文维基百科 → 《外国地名译名手册》类规范 → 历史地名按史学界用法 |
   | 著作、报刊 | 已出版中译本的书名 → 中文学界通称。没有中译本的著作：正文可意译书名，注释里的书目信息保留原文 |
   | 机构、事件 | 官方中文名 → 中文维基和新闻常用名 → 学界用法 |
   | 术语 | 本学科中文教材和中译本的固定译法 → 学界讨论中的常用译法。有派别之分的，选与本书立场相符的并写明 |
   | 虚构作品的专名 | 官方中文版、官方网站 → 用户指定的资料 → 玩家、读者社区的通行叫法 |

   用户的原则是**大家实际在用什么就用什么**：中文维基和讨论区里常用的译法，优先于"更准确"但没人用的新译法。同一名字有多种译法时，按使用频率和权威程度选，别的写进 `aliases_zh` 或 `note`。

3. **查不到时。** 不要自己造一个看起来很确定的音译。
   - 学术、非虚构类的人名：优先保留原文（`keep_original`），正文直接用原文写法。
   - 地名和必须有中文的名字：按通行音译规范暂译（`provisional`）。
   - 虚构作品的角色：可以暂译（`provisional`），最后在书前或书后集中说明这些是暂译，不要在正文里反复加注。
   - 没有通行译法的术语、没有中译本的书名：用达意的说法暂译（`provisional`），首次出现时括注原文。
   - 本书作者：有通行中文名就用；没有就保留原文（`keep_original`），封面和版权页也跟着写原文。

4. **同名和异名。** 不同的人同姓要分别列条（"Li Xiannian"和"Li Lisan"）；中国人名的英文拼写要还原成汉字，威妥玛拼写尤其要查证，不能按读音猜。音同字不同的中文名不查就是错的。

5. **校验。**

   ```bash
   python <skill>/scripts/booktool.py glossary-check glossary/glossary.csv
   ```

6. **请用户看一次。** 把 `conflict` 和没把握的条目单独列出来，附上你的建议。用户直接说的译名优先级最高，记为 `verified`，`basis` 写"用户指定"。

## 翻译过程中维护

- 表不是一次定终身的。翻译中遇到新名字，先查证入表，再继续译。
- 改译名时：改表 → 全书替换 → 重新跑 `check`。**替换时检查搭配。** 比如把"改心"统一成"悔改"之后，"给某人改心"不能机械替换成"给某人悔改"，要改成"让某人悔改"。
- 决定不用的译法写进 `forbidden_zh`，以后 `check` 会自动拦下。

## 完成标准

- `glossary-check` 没有错误；
- 书中反复出现的人名、地名、著作、组织、核心概念都已入表；
- 每条 `verified` 都有依据，暂译的已明确标出。
